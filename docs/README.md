# Documentation map

Start with [English README](../README.md) or [README tiếng Việt](../README.vi.md).
Current user/developer instructions take precedence over historical reports.

| Guide | Audience and purpose |
| --- | --- |

| [Contributing](../CONTRIBUTING.md) | Branch/PR conventions, verification and commit rules |

| [Releasing](RELEASING.md) | CI and source version/tag/release workflow |
| [Changelog](../CHANGELOG.md) | User-facing changes; not a list of internal tasks |

| [Security](../SECURITY.md) | Report sensitive issues privately |

[ADRs](decisions/README.md) explain architectural decisions; [stories](stories/README.md)
record bounded work and its verification. [Tasks](TASKS.md) and `reports/` retain
chronological evidence, including commands/paths from earlier revisions. Those
paths may have been retired and are not current setup instructions. Reports may
contain local machine paths; review/redact before sharing outside this private repo.
