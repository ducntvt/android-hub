# UI polish — 2026-11-17

## Changes

- Language selection now lives only in Hub settings, removing the duplicate
  VI/EN sidebar row.
- Notifications use a 320-point card, tighter spacing, a 28-point close-icon
  target and smaller secondary actions. Cards without actions have no empty row.
- Back, Home and Recents use filled vector glyphs in one quiet toolbar. The
  fourth control rotates the selected visible device by 90 degrees, through its
  authenticated gRPC physical-model API and existing session-generation gate.
- The live framebuffer and its focus bezel both have square corners. No image
  masking, extra frame copy or CPU corner processing was introduced.
- A new two-device H logo is embedded once for the sidebar and packaged as the
  macOS bundle icon. Source and exact imagegen prompt are in
  `crates/desktop/assets/`; iconset intermediates are automatically removed.

Rotation queries the engine's physical orientation, rather than inferring it
from a screenshot or changing Android settings. Apps can retain their own
orientation lock. Screenshot rotation metadata maps touch coordinates back to
the physical panel. Scroll coordinates and axes use the same physical space;
the Android helper converts them into the current logical display space before
framework injection. No per-input shell command or additional polling is used.
